**Arduino Keyboard Español latino!**


Para instalar esta distribución de teclas simplemente hay que reemplazar el KeyboardLayout_es_ES.cpp

Se encuentra en las librerías de Arduino en una carpeta llamada src, reemplazan y listo.


En linux: ~/Arduino/libraries/Keyboard/src/
En Windows: C:\Users\TU_USUARIO\Documents\Arduino\libraries\Keyboard\src\

**Arduino Keyboard Español latino!**





Para instalar esta distribución de teclas simplemente hay que reemplazar los archivos de la carpeta src al de la librería de arduino keyboard / src

En linux: ~/Arduino/libraries/Keyboard/src/

En Windows: C:\Users\TU_USUARIO\Documents\Arduino\libraries\Keyboard\src\

En sus proyectos donde usen esta adaptación llamenlo con la variable KeyboardLayout_es_LATAM
